# AgentFollowUpQueuePanel

Agent 输入框上方的「待投递队列」条。默认只占一行：说明队列状态（正常排队 / 已暂停）与暂停原因，右上角是批量操作与展开切换。用于让用户看清「谁把什么放进了队列、为什么还没送达」，并在不展开的情况下处理它。

## 布局

由两块组成：上方的折叠条（始终可见、固定一行）与下方可展开的条目列表（默认不渲染）。

- 折叠条：状态图标 + 主文案（条数与状态）+ 一行说明；右上角依次是「全部忽略」（队列多于一条时）、「全部送达」（队列多于一条时；解除暂停并把剩下的按顺序全部投递）、「详情 / 收起」。「全部送达」不依赖暂停状态，单条送达过之后仍然可用。
- 展开面板：每条一行，左侧来源徽标（你 / 后台任务 / 未知来源），中间正文（超长截断，悬停显示全文），右侧「送达」与「忽略」。
- 展开面板限高 `max-h-60`，内容超出时在面板内滚动；不引起页面级滚动。
- `390×844` 下折叠条按钮依次换行、正文随之截断，不产生横向滚动。

## 交互

- 点击「详情 / 收起」展开或收起条目列表；折叠态下批量操作同样可用。
- 「送达」：会话空闲时立即投递该条；会话运行中它无法插进当前这一轮，只能置顶到本轮结束后的第一个送出（不打断当前运行）。两种情况点击后该条按钮都立即置灰并显示「已排到最前」，避免重复操作；运行中的悬停提示写明「本轮结束后第一个送达」。
- 「忽略」从队列永久移除该条；「全部忽略」由宿主二次确认后执行。
- 键盘：所有操作都是原生 `button`，可 Tab 聚焦并用 Enter / Space 触发；展开态通过 `aria-expanded` 暴露。

## 数据

- `queue`：队列快照，包含状态（`ready` / `paused`）、暂停原因、自动重试进度与队列项列表；为 `null` 时组件不渲染任何内容。
- `running`：决定单条按钮的文案与语义。
- `canOperate`：为 `false` 时隐藏全部操作按钮，只展示状态与内容。
- `busy`：为 `true` 时禁用全部操作按钮，避免重复提交。
- 事件：`deliver(itemId)`、`dismiss(itemId)`、`resume()`、`request-dismiss-all()`。组件不自己发请求，全部由宿主执行。

## 状态

- 默认（正常排队）：灰色一行，说明「N 条将在本轮结束后送达」或「N 条待送达」。
- 暂停：琥珀一行并附带原因；自动重试超限时说明位置显示「自动重试 N 次仍未成功」。
- 自动重试中：说明位置显示「正在自动重试（第 n/N 次）」。
- 空队列：整体不渲染。
- 不可操作 / 提交中：操作按钮置灰不可点。
- 已提交送达：该条按钮变为灰底灰字「已送达」并不可再点；悬停说明区分「已送达给 AI」（空闲）与「已交给 Agent，本轮结束后送达」（运行中）。

## 不支持

- 不提供队列项内容编辑、重排或完整原文查看（正文是截断预览）。
- 不显示队列项时间戳。
- 不提供跨会话队列总览。
- 不自己发请求，不读写 store 或浏览器存储。

## 隐藏通道理由

- `state:local`：只持有「是否展开」这一个临时状态；队列真实状态全部由宿主通过 `queue` 传入。
