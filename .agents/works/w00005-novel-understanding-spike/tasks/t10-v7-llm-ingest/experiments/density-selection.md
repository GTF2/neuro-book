# 默认建模粒度对照

策略-5作为三阶段基线，独立运行evidences/density-baseline-001的1..6章。评价集预先冻结为query-value-development-001/suite.json（40题），后14章评价集独立保存。评价答案、金标及query-guide不进入ingest输入。

精简候选仍使用相同A/B/C、模型、思考参数、上下文预算、schema、编译、恢复与最多一次语义返工，只调整默认建模粒度。候选提示词在基线结束之后落盘并取得新策略身份，不修改正在运行的8份策略源码。

候选选择规则：Beat按场景、行动目标或话题的实质转换分段；一段连续对话和同一动作过程可以保留在同一个Beat，不按每次说话或表情分裂。只有需要独立检索其内容/来源，或用作关键身份、规则、关系、获知的依据时才另建Disclosure。主要主体、物品实例、持久关系/目标、规则、重要事件变化及明确获知优先；细小动作、重复转述和可由原文轻易补查的修饰不额外建Fact/Episode。关键否定、限定、来源和不能合并的实例不能压缩丢失。已有合法结构不因记录变少而放松校验；不设固定条数上限。

对照记录直接回答、证据支持、补查后回答、总模型费用、修复、pending造成的可用性损失、按类型记录数及诊断次数。阶段合并只有在减少内容后仍有明显A/B重复开销时才进入下一实验；不提前认定调用次数越少越划算。各方案只运行自己的连续前缀，旧策略结果不拼入。
