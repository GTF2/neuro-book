# 20 章产物验收

本页是发布后的独立检查清单，不作为模型抽取、整合或复核的输入。源章段从 t10 capture 读取，不复用 V6 段号；预期语义来自原文及既有场景分析，不能据此手工补改模型 dataset 使检查通过。

## 管线正确性

- 输入 EPUB 哈希、spine 和 20 章来源清单固定，前两章与 t07 source 相同；总计 1922 个 V7 原文段落。
- 所有 20 章有连续无缝 Beat，完成状态来自真实阶段成功；实际语义覆盖报告仍为选取/partial，不是全知。
- 每章有独立 API 提取、整合与复核证据；复核覆盖全部指定单元，失败、修改、重试及未知结果保留。
- t07 parseDataset 通过；所有 typed RecordRef 与有效 revision 一致；原文 UTF-16 Span 匹配，记录和依赖不越过 availableAt。
- 最新快照、按章快照、head 和实际通过前缀一致；相同 run 再执行已完成前缀不增加模型调用或改变旧 snapshot 哈希。
- 不包含凭据或认证头；记录 model、usage、失败、耗时和估价依据，不把未知费用写成零。

## 查询旅程

每组从 `entities` 获取本次生成的 ID，不能假设金标的 su/book/creator 等 ID。必要时翻页、展开深度并记录截断。保存实际返回 ID、有效范围、assertion、assessment、证据与原文。

| 旅程 | 检查内容 |
| --- | --- |
| 苏天晴与原主人 | 同名主体候选与属性归属是否正确；当前意识、身体、身体原主人不因同名混成一个对象 |
| 古书与秘典 | 第 1 章早期能查到黑色古书，后续名称能归到有依据的持续对象；提前 readAt 不显示未来名称 |
| 造物主 | 检索相关发言和苏天晴的显式听闻；不能由 accepted speech 得出造物主内容为真或认识真实身份 |
| 第 8 至 9 章相识 | 第 8 章无名同学与第 9 章报姓名的身份连续性；第 8 章不出现后报姓名、纸条内容或已完成交友 |
| 关系与过程 | 第 9 章的请求、应答、加好友能支持有依据的关系；Episode 能追到跨章相识过程，而不只是共现边 |
| 角色认知差异 | 动机猜测保留持有者与 belief/speech 区别；后续理解不变成当事人实际经历 |
| 20 章情节和摘要 | episode 按条件可遍历；重要持续主体有当前摘要与依据；旧章快照摘要不被第 20 章信息污染 |
| 证据和原文 | 代表性 Fact、Resolution、Episode、Summary 至少各抽查数条，来源精确，解释未越界 |
| 范围与空结果 | reader/角色范围分离；无记录不等于否定事实或 unaware；未来 get/跨范围游标明确拒绝 |

章节 8 至 10 的旧场景分析只用于识别待核查行为，精确坐标使用本轮重新 capture 的正文。发现实质遗漏时应定位召回、提取、整合或复核原因，修改通用策略后按新策略身份重新运行相关连续前缀；不能按问题写入固定小说答案。

未来名称检查同时覆盖 `entities`、全文 `search` 和所命中记录的 `get`/`explain`。身份理由、审查评语、时间描述等自由文本也属于可观察内容；仅 Entity.names 投影为空不能证明没有泄漏。formal-003 的早期自由文本反例保存在 `evidences/formal-003-text-scope-ch03.json`，不得用隐藏某一个搜索字段冒充源数据已修复。

## 报告

记录已通过场景、未表达的查询、发现的错误、修复后重跑与仍存在的语义缺口。运行成功证明管线完成规定工作，不证明自动提取无遗漏或所有回答正确；最终由开发者在这份 20 章产物上进行 Agent 查询体验验收。
