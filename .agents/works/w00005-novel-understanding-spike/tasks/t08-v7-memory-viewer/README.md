## 本地复现

在本 Task 目录执行 `bun run typecheck`、`bun run test`、`bun run build`。构建读取 t07 的 `dataset-v7.json`，生成 [viewer-v7.html](viewer-v7.html)，内嵌数据、代码、样式和图标，浏览器直接打开即可，无开发服务器或 CDN。同 schema 数据也可由页面导入。

`bun run browser` 使用已安装的 Microsoft Edge 和独立临时 profile 运行实际离线自动验收，默认输出到仓库统一系统 Temp 验收根；也可给出显式证据目录。查看器的角色视角消费 t07 显式知情投影，实体详情使用摘要索引选择当前边界各维度最新可用摘要。
