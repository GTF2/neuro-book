# 这次到底改了什么？（写给不看代码的人）

> 配套记录：[t01 实施记录](t01-implementation.md)。界面（UI）没有改动。

## 一句话结论

以前 AI 助手**看不见、也写不了**故事的关键帧（"这条缝从此不能用了""名单被拿走"这类**不可逆变化**）。现在它能读了，也能按规矩写：读帧、读两个帧之间的路标、声明新帧、把"撞错了"的帧走裁决。帧与帧之间的正文怎么写，仍然是人的判定说了算。

## 为什么要做

写作宪法第三条讲的是：人只写不可逆的变化（帧），中间过程交给模型补。但要这么干，AI 得先能拿到帧——之前**一个能读帧的工具都没有**，流程里写着的"读帧/改帧"其实做不到。这次就是把这段接上。

## 改动分三层

| 层 | 改了什么 | 你能看到吗 |
|---|---|---|
| 工具 | 新增 3 个：读帧（列表/详情）、读两帧之间的路标、声明与更新帧 | Agent 面板里 AI 会开始调用这些工具 |
| 给 AI 看的规则 | 新增关键帧说明正文（帧是什么、状态怎么流转、工具怎么用） | 界面不变，属于"规则文档" |
| 写作流程 | 补间环节里写的"调用 Plot API"改成真实工具名；写章节前先确认本章是否落在两个帧之间 | 流程说明更准，AI 少走弯路 |

## 两条你会关心的设计

1. **推翻必须留痕**：AI **不能删帧**。要推翻一个帧，必须同时挂一条创作决策记录（写清决定、动机、风险）——这是宪法第六条。
2. **不喂意图给写字的人**：AI 写正文时看到的帧只有事实（谁死、什么易主）；作者写在帧"备注"里的自由文字**不会**被喂给写字的 AI，免得写出来一股报告味（宪法第五条）。

## 怎么验

- 工具与规则：跑工具测试 28 个用例通过；整个 agent 工具目录 197 个用例通过。
- 效果好坏：需要真跑一次模型，由你判定。
