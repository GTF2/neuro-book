# Task 快照与链接纪律

快照规则的正文在 [创建与执行](../../works/README.md#创建与执行)。Task README 是唯一当前快照：目标／范围与非目标、当前状态、授权来源与限制、下一步或阻塞、合同与有效证据链接；状态变化时替换失效内容，不在底部追加历史。

## Spec 链接的两种合规写法

docs:check 对每个 Task README 强制二选一，漏写会稳定产生警告：

- 链接本次行为涉及的具体 Spec；或
- 明确写一句「行为合同未变」，适用于治理、纯文档、不触碰产品语义的改动。

## 相对链接易错点

- Task 目录在 `.agents/works/<work>/tasks/<task>/`，到仓库根是五层 `../../../../..`，先数再写；`..` 越过仓库根的链接是当前最常见的门禁警告。
- 证据只依赖入库路径：`.local/`、日志与本机生成态不入库，不得作为快照或证据链接目标。不可替代的原始证据进 `evidences/`，恢复用历程进 `walkthroughs/`，小改动不建空目录。

## 完成条件

快照反映当前真实状态，Spec 链接或「行为合同未变」声明存在，全部链接可从本目录解析到入库文件。
