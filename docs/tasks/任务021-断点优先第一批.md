### ① 创世向导薄版（SKILL.md 新增"首次欢迎"节）

触发：项目为新建状态（manuscript 无正文、无 story-concept、PROJECT-STATUS.md 缺失或刚初始化）且用户头一两条消息；老项目/导入/续写不触发。行为：欢迎一句话传达"跟我说一句你的点子就行，剩下的我来办"+ 三条示例开场白（一句话灵感 / 有现成素材 / 完全没想法，可照抄可改），随后顺势进入既有入口判断；用户一口气说完点子时直接接住不为欢迎而欢迎。

**边界说明**：产品无"Agent 主动先开口"机制（grep 全仓零命中——会话都由用户消息触发），协议层能做的最强形式即"新建项目头一两条消息按欢迎框架响应"。"面板一打开 agent 就先说话"需要前端开场消息机制支持，已登记给前线（见遗留）。

### ② 未定回环硬规则（phases/01-project-bootstrap.md 强化 + SKILL.md 占位原则指针）

原规则只有"用户答不上来的内容写入 PROJECT-STATUS.md 的 Pending Questions，不要替用户定死"——只写文件、对话里不提，用户永远看不到。新增双通道硬规则：**写入文件只完成一半，必须同一条回复里在对话中主动逐项向用户提出，每项附 2-3 个候选方向供参考或点选**；只写文件不在对话里问是违规；候选是建议不是替答，用户选一个/给第五个答案/说"先放着"都算闭环。SKILL.md 占位原则行加指针，保证不从阶段一进入时也能看到规则。

**自测**：文本改动，无需跑测试；frontmatter 未动，skill 结构（name/description/when_to_use）零变化，不影响 skill 加载。
