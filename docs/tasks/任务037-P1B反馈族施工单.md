## 契约基线（逐条编号，照计划第一节包 B 行展开）

1. **三分诊五类标准件**（P1-04），每类唯一落件+形态演示+使用时机注释：
   - **Message**：一句话轻量短时不抢焦点、`aria-live=polite`（读屏播报）；成功/提示/警告/错误四色。
   - **Notification**：系统主动、复杂内容、带行动点、可堆叠/暂停/关闭；标题+正文+行动钮三件套。
   - **Alert/Banner**：常驻异常（页面级）、恢复入口、部分失败汇总。
   - **Modal/AlertDialog/Popconfirm**：只用于破坏性确认与不可逆动作（四级弹窗唯一合法用途=蓝图既定）；Esc/取消/确认三路。
   - **Undo/恢复 Toast**：删除/批量/拒绝等可恢复动作的限时反悔条（含倒计时视觉）。
2. **六场景样张**（P1-04 验收）：成功/取消/失败/部分成功/撤销/重试——每场景一个演示件，走「触发→反馈出现→后续」完整闭环。
3. **toast 行为契约**：不抢焦点（断言：出现时 activeElement 不变）+`aria-live=polite`（断言）+自动消失可暂停（hover 停表）。
4. **四态谱**（P1-05），每态「为什么+下一步+是否可重试」三要素齐（断言逐态检查文案三段）：
   - **加载五态**：首次加载/局部加载/按钮 loading/列表加载/长任务 Progress+取消。
   - **空态五种**：首次空/搜索无结果/无权限/没有项目/局部空——Ant Empty 语义参考（说明+行动入口）。
   - **错误六态**：网络失败/超时/离线/重连/保存失败/部分成功。
   - **保草稿铁律**：保存失败/网络断时输入内容一字不丢（断言，照包 A beforeinput 先例）。
5. **复用与禁重写**：`.btn` 家族/`.send-btn` idle 形态/基板 diff-state 类/包 A 输入族样张的表单件（引用其类名规范，禁复制粘贴另一套按钮）；进度条/骨架屏形态照 Ant 语义参考+基板 Token 抄值。
6. **reduced-motion**：装饰动画归零、语义状态直达（照基板既有口径，断言）。
7. **亮暗双主题**：Token 两套全套生效，组件不写死色。
8. **无原生 select/无 display 直切**：新写演示件禁引入 select 与 style.display 跳变（用样张② helper 范式或纯渲染切换）。
