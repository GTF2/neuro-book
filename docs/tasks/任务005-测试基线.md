  ```

  ```

## 目标

在干净 worktree 上全量复跑 monorepo 全部 12 个包的测试，产出一份**测试基线报告**（每包的通过/失败/跳过数与失败摘要），作为后续所有开发任务的对照基线。

背景：前任 2026-09-15 记录的"275 条全绿"只是 neuro-book 包内 5 个选定目录的子集（`server/plot server/config server/agent/workflow plot-tools leader-assets`）；全仓从未统一跑过。本任务补齐这个空白。

## 开工前置

1. 读 `D:\MyProject\neuro-book\AGENTS.md` 的"本 Fork 工作规矩"节（绝对路径，worktree 内向上搜索可能读不到）
2. 读本任务书全文（含运行配置，确认模式/模型已就位）
3. 确认自己在 `D:/MyProject/worktrees/task-005` 目录内（`git rev-parse --show-toplevel` 验证）
4. **worktree 是空白的，生成物都被 gitignore**，必须先跑环境三步（约 2 分钟）：
   ```
   bun install
   bun run --cwd packages/neuro-book nuxt:prepare
   bun run --cwd packages/neuro-book generate
   ```
   注意：`--cwd` 必须放在 `run` 之后；bun install 尾部 "Failed to install 1 package"（json-editor-vue 的 pnpm 强制检查脚本被拦）属已知无害现象。

## 范围与边界

- 允许改动：仅新建 `docs/tasks/evidence/任务005/` 下的基线报告与日志文件；本任务书末尾的交付报告与疑问区
- 禁止改动：任何源码、任何测试文件、任何配置文件、master 分支、`.agents/` 治理文件、其他任务书
- **测试失败不许修代码**——失败本身就是基线信息，只记录
- 不确定时：停下，在任务书"疑问区"登记，待前线答复

## 步骤建议

1. 按开工前置装好环境
2. 主包全量：`bun run --cwd packages/neuro-book test`（无过滤参数，跑全部；预期 5-15 分钟）
3. 其余 11 个包逐一：`bun run --cwd packages/<包名> test`。包清单：neuro-agent-harness、neuro-book-contracts、neuro-book-manager、neuro-book-test-support、nb-memory、nb-history、nb-workflow、nb-ui、llmlint、owned-process、file-snapshot-cache
4. **不要跑** `test:real-model`（真实 Provider 调用，无授权）；其他 `test:*` 变体也不跑，只跑各包默认 `test`
5. 汇总产出 `docs/tasks/evidence/任务005/测试基线.md`，每包一行：命令 / 测试文件数 / 测试条数 / 通过 / 失败 / 跳过 / 时长；失败项附错误摘要（错误消息前 5 行），完整的失败输出另存同目录日志文件
6. 已知锚点对照：前任基线 275 条（5 目录子集）；任务004 实测 server/config 79 条全绿。若这两处数字偏差大，在报告中标注可能原因（从输出推断，不用深查）
