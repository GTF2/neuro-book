## 契约基线（逐条编号，照计划第一节包 D 行展开）

1. **浮层契约**（P1-09）：每浮层声明五件套=唯一 owner（aria-expanded 触发钮）/z-index 层级位/关闭链（点外+Esc+显式关闭钮）/焦点链（开=焦点陷阱入内、关=焦点回触发钮）/aria 三件套（role+aria-modal 视型+labelledby）——样张覆盖四形态：目录抽屉（边缘进入保留任务上下文）/Tooltip（延迟显隐 hover+focus 双路）/Popover（自动翻转不溢出视口）/Workflow 式浮层；窄屏不推挤（浮层覆盖不挤压内容流）。
2. **033 遗留「下层卡 inert」示范落点**：样张内示范 helper inert 锁定范式（aria-hidden 容器内可聚焦件同刻 inert——照任务034 基板接线 helper 既有实现抄值）；**真实下层卡修复归收口轮照范式合并**（本单只示范，不动基板/产品代码——参谋部裁定落点）。
3. **快捷键与帮助层**（P1-10）：快捷键总清单+`?` 帮助层（清单即帮助层内容）；发送/目录/收起 dock/撤销重做键位演示；输入框内冲突规则（键入字符优先于全局快捷键——Combobox 双态口径延续）。
4. **a11y 底座**：skip link（跳 main）、landmark 五件（header/nav/main/aside/footer）、live region（polite/assertive 各一演示）、错误与字段 aria-describedby 关联（照包 A 口径）、listbox 键盘（照 1.3/包 A）、下层卡 inert（条目 2）。
5. **等价规则审计**（P1-10 验收 axe 等价）：断言脚本内置规则清单逐条 DOM 检查——色非唯一状态信号（状态必有文字/图标伴生）/对比度（--ink 对纸面 ≥7:1 抽查 --muted 对纸面 ≥4.5:1，实测 computed 值）/img 与图标 alt/aria 标注/标题层级不跳级/焦点可见（focus-visible 3px 照基板）。
6. **200% 缩放**：浏览器缩放 200% 断言（无横向滚动+关键动作可点——无头用 CSS zoom 模拟+真实缩放移交用户复验，披露）。
7. **响应式五档**（P1-11，档位口径照任务035 澄清③）：桌面三档 1920/1440/1366（完整模式+分栏拖）+窄屏两态 md 768（AI/稿面互斥标签+禁拖+抽屉入口）/sm 390（单栏+抽屉+稳定焦点顺序）——**五张截图各留 DOM 断言**（sm 无横向滚动断言+md 禁拖复用 P1C 窄轮先例+长标题/表格/错误态不溢出）。
8. **i18n/长文案/RTL**（P1-12）：locale 切换演示（zh/en 双语+缺键回退键名可见）；德文长词样例段（长词不断行溢出断言）；日期数字复数格式演示；**RTL 验证**（dir=rtl 翻转后布局不乱/图标不反向错义/关闭钮仍在预期侧——断言+截图）；长文案断言（关键动作不剩省略号+tooltip 兜底全文）。
