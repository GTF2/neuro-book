## 目标

在全新 clone（无 node_modules）上把项目完整跑起来，确认浏览器可用，为后续所有任务提供可运行基线。

## 重要：本机是新 clone

前任档案中的"依赖已装、无需重跑"指他们的旧副本；本仓库是干净 clone，**必须从 `bun install` 开始**。

## 步骤

1. `bun install`（仓库根；Bun 1.4.2 已在 PATH）
2. `bun run --cwd packages/neuro-book nuxt:prepare`（注意 `--cwd` 必须在 `run` 之后）
3. `bun run --cwd packages/neuro-book generate`（生成 Prisma Client ×2）
4. `bun run --cwd packages/neuro-book dev` 启动
5. 浏览器访问 **`http://127.0.0.1:3000`**（必须 127.0.0.1；`localhost` 会解析 IPv6 而应用只监听 IPv4）
6. 用 browser-use 插件（control-browser 技能）截图首页存证

## 已知坑（遇到先按此处理，再怀疑代码）

- 前端空白/不渲染：Agent 沙箱拦截子进程所致——关闭沙箱重试
- 访问失败：确认用的是 127.0.0.1 而非 localhost
- bun 命令打印用法且退出码 0：`--cwd` 位置错了
