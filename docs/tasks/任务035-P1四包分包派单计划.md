## 四、每包验收口径（逐条可留命令输出）

通用底座（每包都跑）：`grep -c "<select"` 样张=0；样张断言脚本全绿（逐条留输出）；亮暗双主题截图各一张（同框内容按包定）；reduced-motion 断言。

- **包A**：Button 12 状态截图/DOM 断言+键盘=鼠标行为一致+loading 禁重复提交断言；Form 错误贴近字段+`aria-describedby` 关联+提交失败焦点到首错+保存失败不丢草稿（断言）；Choice 无原生 select+键盘完整+多选计数与清除断言。
- **包B**：五类反馈各唯一落件断言+成功/取消/失败/部分成功/撤销/重试六场景样张；toast `aria-live=polite` 不抢焦点断言；空错态「为什么+下一步+可重试」三要素逐态断言。
- **包C**：三模式切换+返回不丢草稿+脏状态确认断言；列表/表格 fixture 排序/筛选/分页/批量/空错加载逐条+长数据不横向溢出断言；拖拽鼠标/触摸/键盘三路径+Esc 不提交+md 以下禁拖断言。
- **包D**：每浮层 owner/z-index/关闭链/焦点链/aria 三件套断言；axe 或等价审计+200% 缩放+深浅主题+reduced-motion 四项；响应式档位口径理顺=桌面三档（1920/1440/1366）+窄屏两态（md 768/sm 390）共 **5 张**零溢出断言（「四档布局方向 xl/lg/md/sm」为 CSS 断点族，截图取证按 5 张执行）；locale 切换无截断+读屏完整文案断言。
