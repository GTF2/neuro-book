  1. 模块 `parseMarkdownDocument` 的 body 剥围栏后前导空行，与 `renderMarkdownDocument` 固定补回一个构成**幂等**（剥/补平衡，026 文本版同原理下沉到对象版）。
  2. Lorebook/Character 删私有 parse/render 副本改走模块。
  3. dirty 判定改**对称管道**：磁盘态也走 `parse→createDraft→renderDraft` 再比较（仅 Lorebook/Character/FileDetail 有 dirty 判定；对称管道解决对象版 YAML 键序差异，单侧 normalize 不够）。
  4. FileDetail 从 026 文本版管道（textarea 模式）切换到对象版对称管道（表单模式）；文本版四函数（split/join/normalize/parseWorkspaceFrontmatterText）失去消费者，随之删除（测试同步重写）。
