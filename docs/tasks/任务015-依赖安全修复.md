## 执行步骤

1. **undici（必修）**：`packages/neuro-book` 的 undici 声明 `^7.19.2` 锁定 7.28.0，漏洞区间 >=7.0.0 <7.29.0 → 升到 `^7.29.0`（或更高安全版），`bun install` 更新 lock
2. **@nuxt/devtools（评估二选一并落实）**：critical=GHSA-279x-mwfv-vcqv，经 nb-ui/主应用的 nuxt ^4.3.1 传递引入，仅暴露于 `bun run dev`。两条路线先评估再选：
   - A：bun overrides 强制 `@nuxt/devtools ≥3.3.1`（验证 dev server 与 nuxt 4.4.8 无冲突）
   - B：保持 3.2.4 但锁定 dev server 监听 `127.0.0.1`（核实当前默认绑定，如已默认 127.0.0.1 且不可达外网则记"风险已受控"选 B，零改动）
   - 优先试 A；A 引发兼容问题且排查超 30 分钟则落 B
3. 验证：`bun audit --audit-level=high` 确认 undici 5 条公告清零、devtools critical 消失（或 B 线有受控说明）；`bun run --cwd packages/neuro-book test -- server/config` 回归（基线 79 条）；dev server 冒烟（起服务访问 127.0.0.1:3000 首页可渲染）
