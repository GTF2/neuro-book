## 覆盖清单（前线已确认，按用户真实使用顺序 10 组）

> 背景事实（006 模块地图）：真实业务路由仅 `/`、`/login`、`/admin/*`，主界面全在 `/` 下组件切换；14 个 `*.preview` 路由是开发期组件沙箱。走查主线是"书架 → 工作台内导航"，不是翻路由。

1. **首次打开与进入**：dev 首开加载（白屏期用文字标注）；书架首页（含《新小说》卡片）；卡片 hover 浮层（设置封面/删除）；"需要确认的会话"提示区。
2. **新建项目（主流程①）**：新建书籍入口与表单；必填校验/错误提示态（截得到就截）；新建成功回书架（新卡片）。
3. **进入工作台与大项目加载（主流程②）**：点开 xin-xiao-shuo 后的加载态（Vite 二次预打包静默期，文字标注 + reload 后正常态）；工作台主界面全貌；侧栏章节目录树；角色/世界观档案面板；Agent 会话面板默认态。
4. **写一章（主流程③）**：新建章节入口与编辑器空态；输入中文正文态；编辑器工具栏展开；保存行为（自动/手动，观察标注）；字数统计等写作辅助。
5. **查错（主流程④）**：对当前章节跑检查的入口与检查中状态；检查结果列表（无发现可用含"AI 味"句式的样例文本触发 llmlint）；点击结果条目定位到正文的效果。
6. **Agent 协作流**：会话发起与流式回复态；**只读模式下触发写操作出现的审批弹窗**（任务017 修复的行为，重要回归点）；会话历史列表。
7. **设置与模型配置**：配置中心/模型设置页；Provider 配置表单；**文风预设选择界面**（writer 的 50+ styles，含新加的"防AI味（llmlint·标准）"，enabled: false 默认关）。
8. **管理后台**：`/admin` 首页；`/admin/users`（无需登录可直达；空态/有数据态，018 发现无空态设计）。
9. **关键预览页抽查**：world-engine.workbench-preview（**editorial 主题唯一落地页，008 口径对照物**）、plot-workbench.preview、workflow.preview；其余 preview 页可归并一组薄截（每页 1 张，标注"开发沙箱非用户路径"）。
10. **异常与边界**：/login 登录页（含错误密码提示态）；未配置模型时跑 Agent 的引导/报错态；其他能稳定复现的报错态；截不到的用文字说明卡占位。

预计 35-45 屏。每屏都是"截图文件 + 页面名 + 状态 + 复现方式"四件套。

## 回归机制技术约定（按此实现，勿自造复杂方案）

- 每屏节点带稳定 ID：`data-walk-id="v1-<组号>-<屏号>"`（v2 沿用同 ID 命名规则换版本号）。
- localStorage 键：`walkthrough-v1-feedback-<walk-id>`；导出 JSON 含全部 walkId 与标注快照。
- v1 只需保证：ID 稳定、导出格式完整（含每屏元数据+反馈+三档标记）；v2 的"保留上轮原话/改动标记"在 v2 任务实现（消费 v1 导出文件即可）。
