## 交付报告（前线填写，2026-09-21）

### 做了什么

**必修 A（工具过程行未生效）**：根因=规格包 §2 第 49 行本要求把 `AgentToolNode/AgentToolBubble` 本身"降为过程行形态"（所有工具调用含单个），上批只做了 AgentWorkBlock 聚合块；而真实会话是"跨消息单工具调用"形态，相邻同类聚合几乎不触发 → 用户看到全是卡片。修复：`AgentToolNode.vue` 收起态重写为灰色小字过程行（状态色小图标+工具名+一行摘要+chevron，`text-[11px] text-[var(--text-muted)]`），展开态保留卡片细节；交互类工具（request_user_input 等走 message 模式专用组件）不受影响。单个工具、聚合块、块内工具三级全部落到过程行形态。

**必修 B（刻度条三处错）**：根因=上批挂载把 `AgentSessionScaleBar` 嵌进了滚动容器内部（flex-col 里）→ 跟着内容滚动+布局异常。修复：
- `AgentChatFlow.vue` 模板重构：滚动容器在空状态后闭合，ScaleBar+中面板移到外层 flex 行右缘子项（不随消息滚动）；
- 单击格=打开中面板（新增 `AgentScaleOutlinePanel.vue`：右缘 65% 宽滑入，列该格覆盖的 prompt/answer/work 摘要行，行点击定位正文，头部「查看全部」开完整树）；拖动=按比例滚（点击/拖动 4px 阈值区分）；hover 预览卡跟格移动（顺手修上批遗留"预览卡固定顶部"）；
- 50 格封顶均分聚合覆盖全程（沿上批实现，`SCALE_SEGMENT_LIMIT=50`）；
- 三形态齐备：hover 预览卡 → 点击中面板 → 查看全部完整树（expand-session-tree 通道不变）。

**必修 C（绿环语义错）**：环从"命中率"改为**已缓存 token / 上下文总容量**比例（Surface 侧 `cacheRingRatio` computed=cacheRead/limitTokens，缺数据 null 整环隐藏）；hover 自制小面板五行（已缓存/最大缓存/上传/下载/命中率），数据与 Composer 底部统计条同源 props；点击仍复用 open-context-inspector。零新后端零造数。
