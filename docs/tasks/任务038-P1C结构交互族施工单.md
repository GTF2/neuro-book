## 契约基线（逐条编号，照计划第一节包 C 行展开）

1. **三模式导航**（P1-06）：模式 A（主界面三栏）/B（二级分栏工作区）/C（标签页重编辑器）切换演示——切回不丢状态（断言：A→B→A 后 A 的输入内容仍在）；面包屑返回一级明确。
2. **多标签与脏确认**：多开标签 active/overflow（溢出收窄）+关闭标签脏页确认（脏=未保存改动，关闭必弹确认，弹窗唯一合法用途=破坏性确认照蓝图四级）。
3. **焦点还原**：路由变化后焦点进入 main 区（断言）；刷新后布局还原（localStorage 照基板 1.2 键 `layout.v3.*` 口径）。
4. **可复用列表 fixture**（P1-07）：行选中（单/多/全选/半选态）、批量操作条（选中 N 件+批量钮）、行级操作钮悬停浮现（D-27 通用规则照基板口径）、键盘行操作（↑↓ 移行+Enter 进详情）。
5. **可复用表格 fixture**（P1-07）：列排序（升降切换+aria-sort）、筛选（含筛选无结果空态）、分页（页码+页大小切换）、sticky header、行级 loading/error、长列不横向溢出（断言：长文本截断不撑破）、表格空态（空态三要素照包 B §B 口径）。
6. **虚拟滚动标注**：大数据量场景标注实现策略（本样张 fixture 量级内不实现虚拟滚动，规格条文写清阈值与方案——YAGNI 登记，收口轮定）。
7. **拖拽三路径**（P1-08）：分栏拖拽**指针路径**照基板 1.2 drag-demo 范式（dd-bar role=separator）；新增**键盘路径**（焦点入 separator→ArrowLeft/Right 增减档位（8px 网格吸附照基板空间法）+Home/End 边界）；**触摸路径**（pointer events 已覆盖，断言 touch-action 声明）；`aria-valuenow` 同步（读屏公告）。
8. **拖拽守则**：Esc 取消不提交（回拖前值，断言）；撤销回拖拽前（localStorage 撤销或二次操作）；**md 以下（≤991px）禁拖**（断言：窄视口 separator 无 pointer 行为+抽屉/互斥标签替代）；拖拽不是唯一完成方式（键盘可达即满足）。
9. **reduced-motion**：拖拽预览与列表过渡装饰动画归零、语义状态直达（断言）。
10. **亮暗双主题**：Token 两套全套生效，组件不写死色。
