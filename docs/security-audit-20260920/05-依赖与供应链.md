- **锁文件**：根目录单一 `bun.lock`（Bun workspace 全覆盖），无常见的双锁漂移问题；根 package.json 无 `postinstall` 类可疑钩子（头部已核）。

- **安装源**：bunfig.toml 与各 package.json 的 registry 配置未发现私有镜像/可疑源（头部抽查）。
- 上游自带 `scripts/release` 有打包 security audit 门禁与 sha256 清单（PROJECT-STATUS 多处可见），供应链意识较好。
