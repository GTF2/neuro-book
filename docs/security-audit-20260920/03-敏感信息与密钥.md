# 03 敏感信息与密钥管理

> 方式：对 5463 个 git 跟踪文件做模式扫描 + 人工精读命中项；git 历史做文件名级抽查。网络级验证未做（环境断网）。
> 结论一句话：**没有硬编码的真实密钥，密钥管理体系（掩码/脱敏/校验）做得相当完整；但有"公网服务器 IP 写进文档"这类低风险信息暴露，以及一个设计取舍要知道：API key 明文存在本地配置文件里。**

## 3.1 扫描结论（干净类别——明确未发现）

- 无真实 `sk-`/`sk-proj-`/`sk-ant-` key（唯一命中是脱敏测试的自造样例）、无 `ghp_`/`github_pat_`/`glpat-`、无 `AKIA`、无 `AIza`、无 `xox[abpr]-`、无 JWT、无私钥块。
- 无被跟踪的 `.env`/`.pem`/`.key`/`.p12`/`id_rsa`/credentials 文件（只有两个显式占位符的 example）。
- docker-compose 用 `${NUXT_SESSION_PASSWORD:?}` 强制注入、无默认值。
- git 历史文件名抽查：从未添加过密钥类文件（内容级全历史回溯未做，见覆盖说明）。
- llmlint eval 的 `render-*token-plan-*` 文件是虚构小说语料（"token"指 token 预算实验），抽查确认非密钥。
