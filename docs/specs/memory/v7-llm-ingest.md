# V7 章节 Ingest 实验

## 目标与非目标

从登记样书的 EPUB 正文自动构建可供 V7 查询 CLI 消费的前 20 章记忆快照，包含原文材料、主体及身份依据、命题、显式知情、情节和有依据摘要。模型完成语义提取与跨章整理，程序负责合同校验、坐标、依赖、复核结果应用和原子发布。开发者在 20 章产物交付后评价查询体验，两章金标不再是人工开工门槛。

本能力是独立 spike，不代表生产包接入。首版不实现任意原文修订、全书自主梦境、数据库细粒度版本存储、向量索引、MCP、公开 SDK 或无界语义穷举。不把旧 V6 抽取转换为 V7 代替真实模型 ingest，不把两章金标的答案提供给模型。

## 术语与参与者

章级材料抽取读取编号原文，产出局部指称、提及、披露与连续 Beat。增量整合读取新材料及截至前章的已发布知识，选择或创建持续主体、身份归属、谓词、完整命题、显式知情、情节和摘要。独立语义复核是另一次模型调用，核对候选与原文/既有依据，不以候选自称已验证为准。

候选是结构化 JSON 数据，不可执行。发布快照是通过 t07 唯一 schema、引用、范围、依赖和本能力额外校验的 `neurobook.memory.v7`。语义选择完整性与原文/Beat 覆盖分别报告；每段都有 Beat 不证明语义已抽取完。

增量整合可以补充材料阶段遗漏、但本章原文明确提及的局部指称。补充记录显式保存在 B 候选中，只能新增，不能改写 A 产物；须满足相同的精确提及、唯一 ID 和可见时间约束。合并后的材料全部进入独立复核，不能以补充对象绕过对原错误材料的修订。

## 输入与前置条件

显式指定 EPUB 路径、持久运行目录、处理章数（本次 20）及可选模型配置路径。样书目录按 EPUB spine 确定，剔除正文外的前置材料；正文采用 `epub-body-blocks-v1` 归一化，保留 body 直接块文字、标题和作者声明。第 1、2 章必须与既有 t07 原文的段落和哈希一致。原文文件只读，输入哈希绑定整个运行。

使用 DeepSeek 官方 Chat Completions API 和 `deepseek-flash`，显式设置思考模式及输出上限，JSON 输出仍需本地验证。密钥运行时从显式配置或环境读取；不得写入候选、提示词、审计产物、错误或 Git。模型输入只包含已登记小说、必要前文及已发布前缀知识，不含未来章的语义答案。

2026-09-10 开发者已授权实际 smoke、调试及 20 章调用，不设金额或总调用次数上限，不再逐次审批。单次超时、输出限制、有限连续重试用于控制故障；耗尽当前自动重试后保留进展，由执行 Agent 诊断并继续，不以部分章节冒充全量成功。

开发者进一步澄清：开发和调试无限使用 token，无需考虑开发成本；2026-09-11 明确价格约束针对成品处理单本一千万字的长篇。记录模型输入/输出密度、上下文随长度增长的方式和有效生产调用费用；开发失败、策略试验与调试费用另列，不能拿开发总账直接推算成品价格。没有指定金额门槛时报告估算、敏感因素及主要开销，不擅自宣称开发者已接受某一金额。

## 输出与可观察行为

1. 材料保留精确原文提及和章段，Beat 无缝覆盖每个实际导入章节；材料内容和归属必须来自模型候选及输入，不由程序补造语义。
2. 同名不自动合并。身份映射带来源、理由与复核；新的称呼只能从其提及和身份依据可见时进入名称投影。发言/信念不升级为世界事实，知情严格区分 heard/read/believed/known/unaware；未知不是显式 unaware。
3. 命题保留全部角色、否定、限定、来源归属、故事时间及身份依赖。推断需要明确前提和独立复核；没有证据时保持候选或明确失败，不能用摘要作为新的证据根。
4. 独立复核需覆盖请求中全部语义单元，返回逐项判定和理由。遗漏、重复判定、非法引用或拒绝结论不得被默认通过；修改的候选重新复核。程序可由已通过的直接依据生成 Argument/Assessment 结构，但不得伪造模型的语义判定。
5. 增量整合复用已发布实体及谓词，记录跨章关系和过程；新增事实不因文本相似自动去重，身份和来源差异必须保留。输入候选裁剪或知识缺口在运行报告可见。
6. 每章完成后保存不可变快照及发布记录，最新导出仅推进连续已通过的章节前缀。最终产物可用 t09 `--data` 查询；提供 20 章快照、按章快照、运行统计与查询示例。
7. EntitySummary 合同不变，摘要项目带依赖与评估基础。摘要按章创建新记录，禁止改写旧版本的 `builtFrom` 伪装新鲜。可复用未变化的摘要文字，但需验证其全部依据与评估仍适用。当前快照缺少某历史范围的新鲜摘要时明确报告，历史读取可选择对应章快照。

发布采用整快照版本一致化：每次新发布给全部有效导出节点赋新的统一 revision，并同步全部 RecordRef；Source revision 保持原文版本。保留旧快照及候选日志，同一 ID/revision 的内容永不变化。该策略允许在 t07 单一有效成员合同下增加 Entity 名称，不声称已有生产级细粒度增量存储。

t07 的 `coverage.gaps` 是没有阅读位置的字符串列表，模型逐章语义缺口保留在候选审计和完整快照中。t09 查询输出按 [查询规范](v7-query-cli.md) 在较早 readAt、角色或世界受限范围隐去无法证明可见的语义说明，包含顶层和摘要内嵌 coverage；不能因覆盖说明泄漏未来剧情，也不通过手改已发布数据修复。

## 状态与转换

每个运行固定原文、模型、策略/提示词/输出合同版本。章节按材料提取、整合、复核、校验、发布推进；保存原始请求内容、原始响应、解析结果、验证错误和阶段状态。原始响应持久化后才能标记可恢复验证；已发布阶段重跑不重复请求或发布。

单个运行只允许一个活动写入者。发布前检查当前连续 head 与输入身份；最新指针和章节发布状态不得使查询读到半个快照。文件已写而 head 尚未推进的崩溃可以验证后恢复，不能跳章。中断后从已保存响应/已通过候选继续；请求已发出但响应未落盘的尝试标记结果未知，不保证供应商仅计费一次。

策略、原文或模型配置变化需明确新运行或重跑身份，不能静默覆盖旧尝试。迟到请求响应不应在已取消或失去写入权后推进 head。

## 副作用与数据

读取用户指定 EPUB 和凭据，通过 HTTPS 向 DeepSeek 发送小说输入和提示词，在显式运行目录保存审计与快照。确定性测试使用测试支持包管理的系统 Temp；需持久审查的实际模型开发实验及正式 20 章产物登记在 Task evidence 目录。原文、旧 V6、金标和查看器保持只读。

运行记录请求模型和响应实际模型、用量及缓存命中、耗时、重试与已知/未知费用。公开价格按调用时段估算并注明来源，不宣称供应商账单金额精确。未知结果可能产生费用，不能记为零或从账本抹除。无生产数据库、远端 Git 或部署副作用。

成本报告按材料抽取/整合/复核/重试和每章拆分，区分已知用量估价、未知费用尝试与总耗时。成品设计复用稳定提示词前缀、紧凑候选与有界检索的旧知识上下文；不逐章重发整份历史 graph，不每章用模型重写所有历史主体摘要，不以重复调用替代已保存响应的恢复。输入裁剪必须可审计且保留覆盖缺口，不以减少费用为由跳过必需复核、截掉章节或静默丢弃候选。

## 失败与恢复

配置缺失、认证/余额错误、输入不合法和不可重试 HTTP 错误明确失败；限流、临时服务错误、空输出、截断与结构/语义不通过保存失败后有限重试。错误不能包含密钥或完整认证请求。只有非空完整响应且完成原因正常才进入验证。

结构错误反馈精确字段、引用或章段，不静默丢弃不合法记录补足成功。语义拒绝给出原文和理由供修订；反复拒绝保留候选及问题，不假造 accepted。已发布前缀可继续查询，报告实际完成章数及阻断阶段；修复后恢复不会重复已完成付费调用。

A/B 的结构重试在完整候选可按唯一 ID 寻址时，允许模型返回指定集合内已有记录的完整替换。不能新增、删除、改名或重复替换同一记录；未替换内容保持原样，合成候选仍通过原 schema、原文、引用、时间和完整编译校验，再进入完整 C 复核。首次生成、语义返工及不可寻址的候选输出完整数据；需要拆分、增删或调整顺序时模型须显式请求完整重建，下一次调用恢复完整输出。C 的格式/覆盖修复始终返回完整 C。

原始补丁响应与合成完整候选分别保存；非法补丁不能覆盖上一完整基底，合成后仍不合法时下一修复基于最新合成候选。失败记录显式保存下一响应模式和容量，恢复不靠错误文字推断模式；已保存补丁响应只重新验证，不重复付费请求。成功阶段、独立复核和导出仍消费完整候选，报告按真实调用计费，不因使用补丁而新增或遗漏计费记录。

整合候选在语义复核前执行确定性编译检查。仅整合结构无效时保留已经验证的 A 材料，以原候选和精确错误修复 B；材料错误仍须重做材料并重新审查。输出截断通过有界增加容量处理，不能把截断 JSON 当成成功或反复使用相同不足容量。恢复时保留相同的错误反馈、候选和请求策略，使已保存的有效响应继续可用。

阶段自动尝试用尽时暂停在该阶段并保留前序成功产物，不把尝试耗尽伪装成语义拒绝而无条件重做整章。恢复继续尚未完成阶段。一次校验报告尽可能包含全部可确定的材料错误及引用、首次提及和范围位置，以支持模型定向修复。

语义复核仅拒绝 B、且全部 A 单元通过并无材料漏项时，后续修复保留该 A，以上一 B 候选与具体拒绝理由继续整合，再重新独立复核全部组合候选。A 被拒绝或无法确认材料完整性时重新抽取。跨轮复用必须显式记录原始模型调用来源，报告从真实尝试计费与分类，不能伪造新的 A 调用、漏算旧调用或使同一次调用重复计入。

C 的漏项需显式标明材料层或整合层；整合层漏项且 A 全部通过时可以沿用 A，不能用未分类自然语言的关键词猜测复用资格。来源无法归类时保守按材料问题处理。审查可用位置按所引依据的完整可见时间判断，不要求 Resolution 的 at 恰好等于 Referent 首次提及；不能为了满足审查而提前引用尚未完整可见的披露。

每轮独立 C 输入仅包含本次 A/B 候选、原文及必要旧知识，不传入前一语义轮的拒绝结论，避免把旧候选错误带入已修复数据。C 自身的格式或逐项覆盖错误仍可收到对应阶段反馈，并按已保存响应恢复。

完整命题的身份依赖包含全部实体论元和命题持有者；错误指出具体命题、角色和缺少的显式依据，程序不代替模型挑选身份。命题、追加论证、知情与情节按实际依赖就绪顺序编译，合法的本章相互引用不能因为数组处理顺序被拒绝；循环仍明确失败。

## 边界与兼容

t07 拥有领域 schema、校验与查询投影；t10 仅拥有模型候选格式、运行状态及编译器。候选格式可以更紧凑，但不能弱化最终 V7 语义。t09 通过显式 `--data` 消费导出，无专用后门。新增长期 schema 需求先报告设计证据，不修改金标适配模型错误。

整快照重编译的存储和发布成本随累计记录数增长；本轮量测 20 章，不将其描述为任意长篇的最终持久化方案。按章快照保留历史证据与摘要范围。旧 V7 长期提案的多 manifest 修订、梦境调度和分区失效仍为后续能力，不由本次章级管线暗示已经实现。

成品千万字路径需按原文量和活跃变更接近线性增加模型工作量：每章检索有限候选及其证据、仅更新受影响知识/摘要、独立复核新改语义，周期性跨章整理单独计量。完整快照的累计存储/重编译可能达到平方成本，只是本轮兼容 t07 的实验策略；生产需要不可变增量记录与索引，不能用本实验证明千万字存储已解决。

## 验收与 Smoke

确定性测试覆盖 source 哈希/段落、非法候选/引用/Span、未来范围、身份歧义、发言与世界事实分离、显式知情、复核缺项/拒绝、完整 Beat、追加名称的历史快照、摘要依据和版本。恢复测试覆盖响应保存后中断、半发布、重复调用、原文/策略改变及同目录并发写入拒绝。

真实 smoke 先验证 deepseek-flash JSON 输出与用量，再处理少量实际章节并审查产物；修复后才执行正式 1..20 章。完整运行必须所有 20 章连续发布、原文完整、快照通过 t07、t09 CLI 能查主体/多元命题/知情/情节/摘要与原文依据，且早 readAt 不出现未来名称或证据。独立 Reviewer 检查实现与证据；开发者收到 20 章产物后验证回答质量。
