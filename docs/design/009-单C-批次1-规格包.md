## 3. 会话树内嵌刻度条规格（§2.3，统一贴边刻度交互规格）

- **位置**：面板内容区右缘，宽约 24px（块④定稿尺寸），高度固定。
- **格数**：封顶 **50 格**；对话越长每格聚合越多消息（VSCode minimap 模式），格高下限保证可点击（**绝不缩到选不中**）。
- **交互**：可点击定位；可拖动定位；hover 显示该格覆盖范围摘要（旧库图纸 `0f92cc9a` 放大镜悬停预览，只读学行为）。
- **覆盖式三形态**：hover 小预览卡 → 点击中面板 → 「查看全部」完整会话树（复用现有 SessionTreeDialog 数据源）。
- **覆盖层尺寸**：宽度=内容区 65-70%，高度≤面板高 70%（内部滚动），上下不出面板边界，点外部即收。
- **批次 3 对齐义务**：左缘大纲面板出现时须复用本规格的位置/hover 触发/颜色约定（本规格即"统一贴边刻度"基线）。
