## ② 单D 范围调整建议（三条）

1. **骨架借上游七槽，AI 主舞台落 editor 注册视图**。版 3 三栏=activity+left（驾驶舱/导航）/editor（AI 主舞台视图+稿面组）/right 或 panel（备用容器）的装配配置，不自建三栏 flex；前置任务一项=agent 独立布局模式与七槽的双轨归一（C1）。收益：分屏/收起/持久化/紧凑模式零自研（A1/A2），且为将来吃上游留了路。
2. **标签条/命令体系/状态栏不自制**：稿面「正文｜审稿」标签用 EditorTabBar 底座换皮（A4，宪法 3 选中线是唯一叠加）；设置页与工程师暗门走命令注册+暴露等级（B6）；底部器械条用 WorkbenchStatusBar 空插槽但内容按信息唯一源裁剪（C2）。键盘交互全部走 keymap.ts 声明，禁自写 window 监听（C6）。
3. **主题直接落两轴，三坑入任务书**：学术海军/子夜钴蓝=nbook 主题包两套 colorway（B4），不复兴本地 8 主题 id（C7）；施工任务书固化三条——变量落 `<html>`、NB_POPOVER_Z_INDEX 注入、浮层 Teleport 出 transform/contain 容器（C5，与刻度条踩坑①合并为一条浮层纪律）。消息流四件按 B5 以 bubble/#node 接入，行为底本仍是本地 R2-R5 打磨形态（蓝图 :115）。
