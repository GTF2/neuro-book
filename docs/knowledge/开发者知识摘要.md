## 5. 环境坑位速记（实测沉淀，动工前过一遍）

1. dev server 必须 `127.0.0.1:3000`，localhost（IPv6）失败。
2. Bun `--cwd` 必须放 `run` 之后；`bun --cwd <dir> run <x>` 可能打印用法并假成功（退出码 0）。
3. Agent 沙箱拦截子进程 → 前端空白渲染；先关沙箱再判断代码问题。**任务005 新发现：harness 包 `bun test`（含/不含 `--parallel=1`）全量跑会在 waiting-control-process 系测试挂起，单文件跑正常**——怀疑同族问题。
4. 主应用 CSS 是 UnoCSS；Tailwind 类名在主应用不生效。
5. 全局 `.gitignore` 忽略 `*.log`——测试日志入库要 `git add -f`（任务005 实操）。
6. worktree 涉码任务环境三步重装（bun install → nuxt:prepare → generate），见任务004 执行记录。
7. 本机代理节点不可用时外网（GitHub/竞品官网等）全部不通，但百度等国内站正常；宿主侧工具（WebSearch/图片搜索/宿主 https 下载）不受影响（任务007 实测）。
