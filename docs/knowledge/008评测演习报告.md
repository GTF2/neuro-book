## ② 坑清单（现象 → 原因 → 解法）

1. **IAB 截图功能状态不稳定**（本任务书没预告的新坑）
   现象：任务007 演习时 IAB 截图持续 3s 超时（含空白页）；本任务同一环境截图正常。
   原因：未查明确切根因，疑似宿主进程/会话生命周期相关的临时故障。
   解法：开工先拿任一页面试截一张验证能力；不可用则降级 headless Edge（`--headless --window-size=1920,1080 --screenshot=...`，任务007 已验证可行）。
2. **IAB 上 Playwright role 点击可能超时**
   现象：`getByRole("button", { name: "打开《新小说》" })` click 等待超时，但快照里按钮存在。
   原因：未深查（疑似卡片 hover 悬浮层遮挡可点性判定）。
   解法：快照定位 → 坐标点击（`tab.cua.click`）兜底；注意坐标要落在卡片主体，偏上会点到 hover 才出现的悬浮按钮层（设置封面/删除）。
3. **大项目首次打开触发 Vite 二次预打包**（任务书只预告了"首次加载白屏"）
   现象：点开 224 章项目后 URL 变 `?project=...` 但画面停在书架，静默无进度提示；dev 日志出现 `New dependencies found: yaml, fuse.js, @tiptap/pm/state…`（23 个新依赖）。
   原因：工作台页面用到的依赖首次被 Vite 发现，触发重新预打包，期间旧页面继续渲染。
   解法：等待打包完成（看日志结束）后 **手动 reload 页面**，工作台即正常渲染。正式 008 遇到"点击无效果"先 reload 再排查。
4. **主题覆盖不一致（评测对象口径问题）**
   现象：editorial 米色主题目前**只应用在 world-engine workbench 预览页**（截图⑤）；书架/工作台/设置/管理页仍是蓝白默认主题。
   解法：正式 008 评测前先向前线确认评测对象口径——是"editorial 主题覆盖后的全站"还是"上游新 UI 整体"；截图清单按口径重排。
5. **管理页直接访问可用但注意空态**：`/admin/users` 无需登录可直达（本机 Boot Config 鉴权关闭状态），空列表无空态设计（visual-judge 判失败项之一）——评测深色/浅色主题时记得核对空态页面。

## ④ 对正式 008 的建议

1. **截图清单扩展**：本次工作台只截到欢迎空态，正式评测应加**实写态**（打开章节后的 TipTap 编辑器 + 右侧 Agent 面板展开）、plot 工作台、Agent 聊天流、以及世界引擎预览页之外的 editorial 覆盖页（若覆盖扩大）。
2. **先定口径再评测**：editorial 主题当前仅覆盖 world-engine 预览页（坑 4），008 触发时先确认"评测对象是全站还是主题覆盖页"，否则两层结果没法横向对比。
3. **judge 选型结论**：documents:visual-judge 对网页截图适配良好（返回结构化 JSON、问题定位到坐标/组件），无需尝试其他类型；一次派 5 张合理，更多页建议分组派发。
4. **流程节奏**：硬规则扫描 6 秒可随时重跑，放在每轮截图后立即执行；visual-judge 是最贵一步（~4 分钟/5 张），确认截图合格（无白屏/加载态）再派发，避免返工。
5. **dev server 生命周期**：评测全程保持服务运行（Vite 预打包有会话缓存，二次访问快）；评测完关掉（3000 端口会让下个任务误判环境）。
