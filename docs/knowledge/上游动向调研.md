### 3.2 Task 146：nb-ui shadcn-vue 重构（关键事实）

- **用户已拍板**（上游作者自述）：UI 底座采用 **shadcn-vue**；nb-ui **直接全面重构，不做保守试探**；nb-ui 保持独立发布形态（neuro-book-site 依赖它）。
- **技术要点**：交互内核用 **Reka UI**（要真实 ARIA 语义 + 键盘/焦点测试证据）；颜色只准来自主题变量合同；图标方案阶段 0 先实测动态图标名。
- **阶段路线与进度**：阶段 0 图标策略 → **阶段 1 框架替换 → 阶段 1.5 主题系统（2026-08-15 rounds 5-13 已收口）** → 阶段 2 定制 NeuroBook 风格组件 → 阶段 3 主仓领域无关组件搬入重写（功能不得低于主仓现版） → 阶段 4 才接入主仓（此前主仓零业务改动）。
- **设计语言**："编辑室工作台"方向（2026-08-10 拍板）：**主题从 8 套砍到 5 套（D10 新阵容）、双区制、5 组新 token**。规范落在 nb-ui 仓 `docs/design-language.md`（默认主题设计语言+踩坑清单）与 `docs/authoring-themes.md`（主题格式）。
- **主仓可见的落点**：`packages/nb-ui/themes/editorial/`（主题 + manifest + vars.css，**含明暗双视觉 e2e 快照**）——编辑室方向已部分落进主仓的 nb-ui 包；主仓主题现状是 8 套/36 变量（`app/utils/theme/README.md` v2.1，theme-tokens.ts 为事实源）。
