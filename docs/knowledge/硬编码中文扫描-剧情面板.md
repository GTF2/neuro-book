# 硬编码中文扫描——剧情面板（novel-ide plot）

- 扫描域：剧情面板（剧情/大纲/outline/plot 相关）。世界引擎（world/lore/设定）归另一域，本报告不覆盖。
- 扫描根：`packages/neuro-book/app/components/novel-ide/plot/`（53 个文件 = 45 `.vue` + 13 `.ts`；`NovelPlotPanel.vue` 在该目录内）。
- 范围核实：`find app -iname "*outline*" -o -iname "*scene*"` 在 plot 目录外无命中，plot 目录即剧情面板全集。
- i18n 现状核实：`grep -rln '\$t(\|useI18n\|useLocale' plot/` → 0 命中，**剧情面板整域未接 i18n**。
- 键名风格依据：`app/i18n/locales/zh-CN.ts` 已有 `ide.chapterPanel.*`、`ide.workspaceStage.*` 先例，本报告统一建议挂在 **`ide.plotPanel.*`** 命名空间下，跨文件复用文案放 `ide.plotPanel.common.*`；可复用现有全局键（`common.cancel` 等）的条目单独标注。

## 方法与命令

```bash
# 1) 抓取全部含中文的行（含行号）
grep -rnP "[\x{4e00}-\x{9fff}]" packages/neuro-book/app/components/novel-ide/plot --include="*.vue" --include="*.ts"
# 2) 剔除整行注释（// /* * <!-- 开头）
… | grep -vP ":[0-9]+:\s*(//|\*|/\*|<!--)"     # → 953 行非注释
# 3) 用 Bun 脚本逐行提取引号字符串 / 标签文本节点中的中文最小片段，按文件分组后逐条人工审定
```

- 共 953 处非注释硬编码中文，人工逐条审定为两类：
  - **A 类：用户可见 UI 文案**（796 处）——需迁 locales，逐条列于下文各表。
  - **B 类：预览/mock 示例数据**（157 处）——测试页假数据（小说名、场景摘要等），非 UI 文案，见文末 B 类说明。
- 已排除：`//`、`/* */`、`<!-- -->` 注释中的中文（任务要求跳过）。仅 7 行含 `//` 且均为 `scene://` URI scheme 或数据行，无行内注释混入误判。
- 长行摘录以「…」截断，只保留中文文案部分；行号为扫描时点 worktree 的真实行号。
